What you get

ZP

Zone price board

Today, yesterday and tomorrow across every European bidding zone.

 DA

Day-ahead curves

Hourly and 15-minute prices with baseload, peak and yesterday overlay.

 LOAD

Load vs forecast

Actual demand against the ENTSO-E forecast, live.

 RES

Wind and solar

Forecast against actual for onshore, offshore and solar.

 FLOW

Cross-border flows

Scheduled and physical flows on any interconnector.

 GEN

Generation stack

The mix by fuel type, as a bar stack or over time.

 CAL

Market schedule

Countdowns to SDAC and IDA gates, publications and settlements.

 FUT

Wider market

TTF, Brent, EUA, FX and rates plus an energy news wire.

Runs where you work

Terminal

A single binary for macOS and Linux. Charts render with Kitty graphics in Ghostty, Kitty and WezTerm, and fall back to block characters everywhere else. Works over SSH.

$ surge da DE-LU --json
$ surge quote TTF=F --csv

Desktop unsigned preview

Native windows on macOS (Apple Silicon) and Windows with the same panes, command bar and plugins. The builds are not code-signed yet, so expect a Gatekeeper or SmartScreen warning on first launch.

Signed builds will follow once the project has a developer account.

Install

macOS / Linux

$ curl -fsSL https://nickmcblain.github.io/surge/install.sh | sh

Installs the terminal binary to ~/.local/bin. Add SURGE_DESKTOP=1 on Apple Silicon to install the desktop app instead.

Homebrew

$ brew install nickmcblain/tap/surge

Windows

Download SurgeSetup.exe from the latest release. Installs the desktop app and the surge command.

From source

$ git clone https://github.com/nickmcblain/surge && cd surge $ bun install && bun run dev

Needs Bun 1.4 or newer. Full installation guide.

Bring your own ENTSO-E token

Power data comes straight from the ENTSO-E Transparency Platform. Register there, email the helpdesk for Restful API access, and paste the token into Surge with the ENTSOE command or SURGE_ENTSOE_TOKEN. Everything else — futures, FX, news, the schedule — works without it.

How to get a token · Nothing leaves your machine; Surge has no backend.
